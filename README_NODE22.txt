GESTION AVIONS - Node.js 22.11.0

IMPORTANT:
Ne lancez PAS `ng serve` si votre Angular CLI global est en version 22.
Ce projet utilise Angular 19.2.15, compatible avec Node 22.11.0.

1) Ouvrir un terminal dans ce dossier.
2) npm install
3) npm start

Ou double-cliquer sur demarrer.bat apres npm install.

Si vous voulez absolument utiliser `ng serve`, installez le CLI global 19.2.15:
npm uninstall -g @angular/cli
npm install -g @angular/cli@19.2.15
Puis: ng version
Puis: ng serve
